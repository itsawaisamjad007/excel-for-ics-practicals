# 📊 LibreOffice Calc / Microsoft Excel - Beginner to Professional Guide

> Designed for students, self-learners, and aspiring Cyber Security professionals.

## 📖 About This Repository

This repository contains structured notes, diagrams, practical examples, and visual learning resources for **LibreOffice Calc** and **Microsoft Excel**.

The goal is to build a strong foundation—from understanding the interface to using formulas, formatting, charts, data analysis, and real-world spreadsheet skills.

The content is also suitable for:

- ICS Computer Practical Preparation
- College & University Students
- Beginners Learning Spreadsheets
- Office Productivity
- Cyber Security Report Management
